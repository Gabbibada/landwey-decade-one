# LandWey @ 10: Decade One (2016–2026)
### Commemorative Digital Monograph Preview

An interactive, responsive digital publication viewer for the 10-year commemorative magazine of **LandWey Investment Ltd**.

- **Format:** 80 Pages / 41 Double-Page Spreads
- **Typography:** Baskerville Bold, Bitstream Charter Roman, Avenir Next
- **Palette:** Imperial Sovereign Gold (`#C5A059`), Obsidian Black (`#0D0D0D`)
- **Features:** Double-spread viewer, chapter quick-jump drawer, responsive touch controls, high-res PDF download link.

Hosted via GitHub Pages.
